Using Generative AI in the PMRC Workshop

Find your institution below to see how to connect an LLM and use the workshop's R wrapper. If your institution adds nothing special, the Quick Start works for everyone.

Workshop Quick Start — do this to use the notebooks today

  1. Get an API key from one provider:
    • OpenAI (free trial credit, then ~pennies/run) — env var OPENAI_API_KEY
    • Anthropic Claude (free trial credit, then low pay-as-you-go) — env var ANTHROPIC_API_KEY
    • Google Gemini (free tier) (standing free tier) — env var GEMINI_API_KEY
  2. Open the workshop Colab notebook your presenter shares at the session (the link is distributed live and changes each time):
    • LLMs for Image Annotation
    • LLMs for Text Annotation
  3. Each workshop notebook starts with a Connect cell like this. Set PROVIDER to what you registered, paste that provider's key, and run it: 
    source("https://raw.githubusercontent.com/mro0001/pmrc-genai-workshop/main/provider_wrapper.R")
PROVIDER <- "openai"     # whichever you registered: "openai" | "claude" | "gemini"
set_api_key(PROVIDER, "PASTE-YOUR-KEY-HERE")
  4. Run the rest of the notebook — its new_chat(PROVIDER) calls do the rest. set_api_key picks the right key variable for you, so switching providers is a one-word change.
