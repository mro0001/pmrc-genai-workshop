Presenter Integration Guide

1. Host the wrapper

Put provider_wrapper.R in the public repo so notebooks can source it: https://raw.githubusercontent.com/mro0001/pmrc-genai-workshop/main/provider_wrapper.R

2. Onboarding cell (top of each notebook)

source("https://raw.githubusercontent.com/mro0001/pmrc-genai-workshop/main/provider_wrapper.R")
Sys.setenv(OPENAI_API_KEY = "sk-...")   # participant pastes their key
PROVIDER <- "openai"; MODEL <- "gpt-4o-mini"
chat <- new_chat(PROVIDER, model = MODEL)

3. Constructor swap (both notebooks)

# BEFORE
chat0 <- chat_openai(model = "gpt-4o-mini")
# AFTER
chat0 <- new_chat(PROVIDER, model = MODEL)

Apply to every chat_openai(...) call in the image-annotation notebook and the text-annotation notebook. Downstream $chat(), $chat_structured(), content_image_file(), and type_*() calls are unchanged.

4. Provider → default model

  • openai → model gpt-4o-mini
  • claude → model NULL (ellmer default)
  • gemini → model gemini-2.0-flash

All three defaults are vision-capable, so the image notebook works on any of them. Text-only models cannot see images.

5. Security (required)

Remove the hard-coded OPENAI_API_KEY literal from the image-annotation notebook and rotate that key — treat it as leaked. Keys come from the onboarding cell only.
