Workshop Quick Start — do this to use the notebooks today

  1. Get an API key from one provider:
    • OpenAI (free trial credit, then ~pennies/run) — env var OPENAI_API_KEY
    • Anthropic Claude (free trial credit, then low pay-as-you-go) — env var ANTHROPIC_API_KEY
    • Google Gemini (free tier) (standing free tier) — env var GEMINI_API_KEY
  2. Open the workshop Colab notebook your presenter shares at the session (the link is distributed live and changes each time):
    • LLMs for Image Annotation
    • LLMs for Text Annotation
  3. In the notebook's onboarding cell, paste your key, set the provider, and run: 
    source("https://raw.githubusercontent.com/mro0001/pmrc-genai-workshop/main/provider_wrapper.R")
Sys.setenv(OPENAI_API_KEY = "sk-...")   # your key (use the env var for your provider)
PROVIDER <- "openai"; MODEL <- "gpt-4o-mini"
chat <- new_chat(PROVIDER, model = MODEL)
  4. Run the rest of the notebook — new_chat() handles the provider.

Your institution's own options

Kobe Gakuin University provides chat tools (a login, not a developer key), so for the workshop use the Quick Start key above.

Sensitive / IRB data

No campus tool; cautionary advisory on external tools and confidentiality.

For human-subjects or otherwise sensitive data, prefer a local model (new_chat("ollama", ...)) or your campus gateway — not a public API and not the live Colab session.
