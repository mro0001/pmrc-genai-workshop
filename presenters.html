Presenter Integration Guide

Both workshop notebooks are already wired to the wrapper. This page documents how it works, plus the one item that still needs a presenter.

1. The wrapper lives in the repo

The notebooks source() it from https://raw.githubusercontent.com/mro0001/pmrc-genai-workshop/main/provider_wrapper.R. Edit it there and every notebook picks up the change.

2. The Connect cell (top of each notebook)

One lean cell replaces the old multi-cell setup. A participant only sets PROVIDER and pastes a key. set_api_key() stores it under the right variable automatically, so switching providers is a one-word change.

source("https://raw.githubusercontent.com/mro0001/pmrc-genai-workshop/main/provider_wrapper.R")
PROVIDER <- "openai"     # "openai" | "claude" | "gemini"
set_api_key(PROVIDER, "PASTE-YOUR-KEY-HERE")

The image notebook’s Connect cell also sets MODEL <- "gpt-4o-mini" (a vision model). The text notebook defers model choice to the 2×2 comparison near the end (MODEL_A / MODEL_B).

3. Constructor pattern

# was   chat0 <- chat_openai(model = "gpt-4o-mini")
# now   chat0 <- new_chat(PROVIDER)                 # text notebook (default model)
#       chat0 <- new_chat(PROVIDER, model = MODEL)   # image notebook (pinned vision model)

Every chat_openai(...) call was swapped to new_chat(PROVIDER, ...). Downstream $chat(), $chat_structured(), content_image_file(), and type_*() calls are unchanged. Pass model= only when you want a specific model.

4. Provider → default model

  • openai → model gpt-4o-mini
  • claude → model NULL (ellmer default)
  • gemini → model gemini-2.0-flash

All three defaults are vision-capable, so the image notebook works on any of them. Text-only models cannot see images.

5. Security (still needed)

The image-annotation notebook still holds the old hard-coded OPENAI_API_KEY in the API-key section just below the Connect cell. Delete that markdown cell, the hard-coded-key cell, and the Sys.getenv check (the Connect cell replaces all three), then rotate that key at platform.openai.com. Treat it as leaked.
