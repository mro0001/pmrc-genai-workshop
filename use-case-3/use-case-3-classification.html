1 · Compliance — the code

Python 
# % missing, % valid label
def compliance(recs):
    n = len(recs)
    miss  = sum(r["category"] in (None,"")
                for r in recs)
    valid = sum(r["category"] in CATEGORIES
                for r in recs)
    return {"pct_missing": 100*miss/n,
            "pct_valid":   100*valid/n}
R 
# tidyverse
compliance_table <- function(runs) runs |>
  group_by(model, prompt) |>
  summarise(
    pct_missing = 100*mean(is.na(pred)),
    pct_valid   = 100*mean(pred %in% CATEGORIES),
    .groups = "drop")

2 · Accuracy — the code

# exact match vs gold standard
def accuracy(recs):
    pairs = [(canon(r["category"]),
              canon(r["gold"])) for r in recs]
    pairs = [(p,g) for p,g in pairs if p and g]
    return 100*mean(p==g for p,g in pairs)
R 
# tidyverse
accuracy_table <- function(runs) runs |>
  group_by(model, prompt) |>
  summarise(
    accuracy = 100*mean(pred == gold,
                        na.rm = TRUE),
    .groups = "drop")

2 · Accuracy — is the gap real?

McNemar's test

  • Goal: the models' accuracies differ (83 vs 80 vs 82) — real difference, or run-to-run noise?
  • Step 1. Score every prediction right/wrong against the human gold standard.
  • Step 2. Pair two models on the same bio (and iteration).
  • Step 3. Keep only the disagreements — bios one model gets right and the other wrong.
  • Step 4. Exact binomial test on those discordant counts → a p-value.

Paired and per-item — the right test when both models see the exact same data.

2 · McNemar — the code

Python 
# statsmodels, exact binomial
from statsmodels.stats.contingency_tables \
     import mcnemar

df["correct"] = (df.pred == df.gold).astype(int)
a = df[df.model==m1].set_index(["id","it"]).correct
b = df[df.model==m2].set_index(["id","it"]).correct
tab = [[((a==1)&(b==1)).sum(), ((a==1)&(b==0)).sum()],
       [((a==0)&(b==1)).sum(), ((a==0)&(b==0)).sum()]]
mcnemar(tab, exact=True)        # .statistic .pvalue
R 
# exact McNemar = binom test on discordants
a <- df$correct[df$model == m1]   # aligned by
b <- df$correct[df$model == m2]   # id + iteration
tab <- table(a, b)
binom.test(tab["1","0"],
           tab["1","0"] + tab["0","1"], 0.5)

3 · Precision — the code

Python 
# agreement + Krippendorff alpha
def precision(recs):
    items = defaultdict(list)
    for r in recs:
        items[r["id"]].append(canon(r["category"]))
    agree = [len(set(v))==1 for v in items.values()]
    return {"agreement_rate": 100*mean(agree),
            "kripp_alpha": kripp_alpha_nominal(items)}
R 
# tidyverse + base-R alpha
precision_table <- function(runs) runs |>
  group_by(model, prompt) |>
  summarise(
    agreement_rate = 100*mean(all_agree(pred)),
    kripp_alpha = kripp_alpha_nominal(
                    pred, iteration),
    .groups = "drop")
